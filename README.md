Entry for the make.fun competition [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## The pitch

> Your futsal group still splits the bill in a chat thread - tell make.fun the idea in plain words and an AI agent builds the little app tonight, and next game everyone just taps.

One sentence, 177 characters. It pitches a non-coder friend on letting an AI agent build their first app idea on make.fun — using the most relatable example possible: the futsal group that still splits the bill in a chat thread. No code, no jargon, just plain words in and a working little app out by tonight, ready for the next game.

## Why it works

The pitch starts from a pain everyone recognises — splitting a bill in a chat thread — then shows the whole make.fun promise in one breath: describe the idea in plain words, an AI agent builds it tonight, and by the next game the group just taps. The friend never has to learn to code; the app meets them where they already are.

## How it works

Run `main.py` (stdlib-only Python 3). It writes the exact pitch text to `/output/entry.txt`.

```bash
python3 main.py
cat /output/entry.txt
```
